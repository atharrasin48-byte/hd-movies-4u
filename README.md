# HD MOVIES 4U

A responsive movie-discovery website starter.

## Current status
- Static front-end prototype in `index.html`
- Search and language/category filters
- Movie detail view with sample placeholder metadata
- Links are placeholders to official trailer and legal streaming discovery pages

## Important before launch
- Replace fictional sample entries with verified metadata.
- Use only artwork you own or are licensed to use.
- Add a secure backend and authenticated admin workflow before enabling public content management.
- Only link to authorized streaming/download sources; this site does not host movie files.

## Deploy
This is a static site. For Cloudflare Pages, connect this repository and use the root directory `/` with no build command; output directory `/` (or `.` depending on the dashboard field).
